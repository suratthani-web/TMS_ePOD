Checklist คนขับ

4 ข้อสำคัญที่ต้องทำทุกเที่ยวงาน

ปฏิบัติตามนี้เพื่อป้องกันงานตกหล่นและให้การเบิกจ่ายราบรื่น

📍

1. เปิด GPS (ตำแหน่งที่ตั้ง) ตลอดเวลา

อนุญาตให้แอปเข้าถึงตำแหน่งเสมอ เพื่อให้ระบบบันทึกพิกัดและเวลาเข้า-ออกจุดรับ/จุดส่งได้อย่างแม่นยำ

📷

2. ถ่ายรูปสินค้าและบิลให้คมชัด

รูปถ่ายรับสินค้าและรูปส่งมอบ (ePOD) รวมถึงลายเซ็นลูกค้า เป็นหลักฐานสำคัญในการยืนยันปิดงานและคิดค่าเที่ยว

✅

3. กดอัปเดตสถานะตามจริงทุกจุด

กดตามลำดับจริง: เริ่มงาน → ถึงจุดรับ → รับสินค้าเข้า → ถึงจุดส่ง → บันทึกส่งงาน ห้ามกดข้ามหรือรอกดทีเดียว

🚨

4. พบปัญหา / สินค้าเสียหาย แจ้งทันที

หากติดต่อลูกค้าไม่ได้ สินค้าชำรุด หรือแอปขัดข้อง ให้ถ่ายรูปเก็บไว้และติดต่อแอดมิน/แจ้งเหตุ SOS ทันที

ติดปัญหาหน้างาน? ติดต่อแอดมิน / ศูนย์ควบคุมทันที หรือใช้ปุ่ม SOS / แชทภายในแอป DRouteMind ได้ตลอด 24 ชม.
